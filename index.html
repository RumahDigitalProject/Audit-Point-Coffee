Mulai Audit Baru

Pilih mode audit sesuai kebutuhan:
• Gudang Saja: Hanya input stok fisik RAW (semua segel). Tanpa input konversi.
• Kabinet / Booth Saja: Input fisik RAW dan KONVERSI.
• Gabungan (Gudang → Kabinet/Booth): Input semua barang di Gudang dulu (khusus RAW), lalu pindah ke Kabinet / Booth (RAW + KONVERSI) dalam satu sesi audit.
Master PLU masih kosong. Silakan masukkan data terlebih dahulu.
